# AdventurePilot Instructions

User-facing documentation for AdventurePilot features.

This is an orphan branch: it shares no history with the code branches and is
never merged into them. It exists only to hold plain-English guides, FAQs, and
how-to notes for people driving with AdventurePilot, kept separate from the
source tree so the docs can change without touching a code branch.

## Layout

One file (or folder) per feature. Add new pages here as features ship.
